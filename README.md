 📊 Data Analytics Project

Overview

This project demonstrates an end-to-end Data Analytics workflow, from loading and cleaning raw data to SQL analysis, dashboard creation, reporting, and presentation.

The goal is to extract meaningful insights from the dataset and present them through Python, SQL, and Power BI.

Dataset

The dataset contains business/customer-related data used for:

- Data cleaning and preparation
- Exploratory Data Analysis (EDA)
- SQL-based analysis
- KPI and trend analysis
- Power BI dashboard development

🛠️ Tools & Technologies

- Python — Data loading, cleaning & EDA
- Pandas & NumPy — Data manipulation
- MySQL / SQL Server — SQL queries & analysis
- Power BI — Interactive dashboard
- Microsoft PowerPoint — Project presentation
- Claude AI — Presentation/report assistance

🔄 Project Steps

1. Data Loading

Loaded the dataset into Python using Pandas and explored its structure, columns, and data types.

2. Exploratory Data Analysis

Performed EDA to identify patterns, trends, missing values, duplicates, and potential data quality issues.

3. Data Cleaning

- Handled missing values
- Removed duplicates
- Corrected data types
- Standardized data where required
- Prepared the dataset for analysis

4. SQL Analysis

Imported the cleaned data into MySQL / SQL Server and performed SQL queries using filtering, aggregation, joins, subqueries, CTEs, and window functions where required.

5. Power BI Dashboard

Created an interactive dashboard with KPIs, charts, filters, and visualizations to communicate key findings.

6. Report & Presentation

Prepared a project report summarizing the methodology and findings. Created a PowerPoint presentation with assistance from Claude AI to present the project and insights.

▶️ How to Run

1. Clone or download this repository.
2. Install the required Python libraries.
3. Open the Python/Jupyter Notebook.
4. Place the dataset in the appropriate folder.
5. Run the Python analysis and data-cleaning steps.
6. Import the cleaned dataset into MySQL / SQL Server.
7. Run the SQL queries.
8. Open the Power BI ".pbix" file to explore the dashboard.
